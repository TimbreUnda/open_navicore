# Support

Open NaviCore is an early-stage interoperability project, not a supported
consumer navigation product.

- Use GitHub Discussions for design questions and general help when enabled.
- Use the issue templates for reproducible bugs and scoped feature proposals.
- Use the process in [SECURITY.md](SECURITY.md) for security-sensitive reports.

Include the Git revision, firmware family, build command, complete error text,
and whether the issue is host-only or reproduced on authorized stationary bench
hardware. Do not upload proprietary binaries, credentials, personal data, or
location history.
