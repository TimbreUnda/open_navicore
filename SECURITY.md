# Security policy

## Supported versions

Open NaviCore is pre-release research software. Security fixes are applied to
the current `main` branch; no released version currently receives long-term
support.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could enable code
execution, persistent device compromise, unsafe vehicle behavior, credential
exposure, or disclosure of personal/location data.

Use GitHub's private vulnerability reporting for this repository. If that
feature is unavailable, contact an organization owner through GitHub before
sharing reproduction details. Include the affected revision, impact, minimal
reproduction, and whether the finding was reproduced on stationary bench
hardware.

Do not test against vehicles or devices you do not own or have explicit
permission to modify. Do not include proprietary binaries, secrets, or personal
data in a report.
